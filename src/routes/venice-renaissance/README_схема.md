# Схема связей: «Гении Венецианского Возрождения»

Три версии одной и той же сети — выбирайте под задачу.

| Файл | Что это | Когда использовать |
|---|---|---|
| `Гении_Венецианского_Возрождения_v2.xmi` | доработанная диаграмма Umbrello (25 компонентов, 34 зависимости) | продолжить работу в привычном редакторе |
| `venice_network.mmd` | Mermaid-исходник (текст) | вставка в Markdown, GitHub, Obsidian, Notion, MkDocs |
| `venice_network_mermaid.html` | та же схема, отрендеренная в браузере | быстрый просмотр и правка без установки чего-либо |
| `venice_network.html` | интерактивная схема на vis-network | вставка на веб-страницу: зум, перетаскивание, пояснения по клику |
| `venice_network_preview.png` | статичное превью 1904×961 | вставить в презентацию или документ |

Логика слоёв: сверху — те, кто платит и наказывает; в середине — те, кто пишет; снизу — среда, из которой приходят техники и заказы. Поэтому большинство стрелок идёт вертикально и схема читается без пересечений.

## Как править

### Mermaid (проще всего)
Откройте `venice_network.mmd` в любом текстовом редакторе. Узел — одна строка, связь — одна строка:

```
A6["Тициан<br/>1488–1576"]          %% узел: id["подпись"]
A6 -->|покровительство, 1533| P6    %% связь: от -->|подпись| к
```

Проверить результат: https://mermaid.live (вставьте текст) или откройте `venice_network_mermaid.html`.

### vis-network (для веб-страницы)
В `venice_network.html` в начале скрипта лежат два массива — `nodes` и `edges`. Добавление участника — одна строка:

```js
{ id:"P11", label:"Дож", group:"pat", title:"...", desc:"..." },
```

Вставка на сайт — через iframe, ничего собирать не нужно:

```html
<iframe src="venice_network.html" style="width:100%;height:720px;border:0"></iframe>
```

Файл автономный, но библиотека vis-network подгружается с CDN. Если нужен полностью офлайн-вариант, скачайте `vis-network.min.js` и замените ссылку в `<script src=...>` на локальный путь.

### Umbrello
Откройте `..._v2.xmi`. Компоненты расставлены по сетке, связи проведены напрямую; при желании двигайте мышью — Umbrello пересчитает линии сам. Исходный файл не изменялся.

## Чем ещё можно заменить Umbrello

| Инструмент | Сильная сторона | Слабое место |
|---|---|---|
| **Mermaid** | текст в git, рендер везде, ноль зависимостей | автоматическая раскладка, ручная компоновка ограничена |
| **vis-network** | интерактив, зум, тултипы, один HTML-файл | нужен JS, нет «коробочного» редактора |
| **Cytoscape.js** | мощная аналитика графа, фильтры, раскладки | круче кривая входа, чем у vis-network |
| **D3** | полный контроль над отрисовкой | всё руками, для схемы на 25 узлов избыточно |
| **Graphviz (DOT)** | лучшая автоматическая раскладка для генеалогий и сетей | устаревшая эстетика, плохо с кириллицей по умолчанию |
| **Kumu** (kumu.io) | веб-редактор специально под карты связей, iframe-вставка, фильтры по слоям | облако, бесплатный тариф публикует проект |
| **draw.io / diagrams.net** | привычное рисование, вставка в Confluence/Notion | связи не «умные»: перетаскивание узла не двигает логику |
| **Obsidian Canvas** | бесконечное полотно, локальные файлы | только внутри Obsidian |

Для исторических тем с акцентом на связи я бы держал **Mermaid как источник правды** (диффится в git, живёт рядом с текстом) и **vis-network как публичную версию** (красиво и интерактивно). Umbrello оставить для случаев, когда нужна строгая UML-нотация.

## Оговорка

XMI собран программно по образцу вашего файла (та же структура `packagedElement` / `componentwidget` / `assocwidget`, те же атрибуты и типы). Открыть Umbrello в этой среде нельзя, поэтому файл проверен только на валидность XML и целостность ссылок между элементами. Если при открытии что-то отобразится не так — исходный набросок сохранён без изменений, а схему можно быстро пересобрать из `venice_network.mmd`.
