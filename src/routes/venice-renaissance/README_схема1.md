

## Лента времени (добавлено)

| Файл | Что это |
|---|---|
| `venice_timeline.mmd` | Mermaid `timeline`: 29 событий 1430–1594, три периода |
| `venice_lifespans.mmd` | Mermaid `gantt`: годы жизни мастеров, видно пересечения |
| `venice_timeline.html` | обе схемы на одной странице, с полями для правки |
| `venice_timeline_preview.png` | превью ленты, 3600×416 |
| `venice_lifespans_preview.png` | превью «годов жизни», 2000×307 |

Правило синтаксиса ленты: `год : событие : событие`. Двоеточие — разделитель, поэтому внутри текста события его использовать нельзя (заменяйте на тире). События одного года перечисляются в одной строке и встают в одну колонку.

Лента намеренно разбита на три периода, а не на «поколения художников»: при разбивке по мастерам даты начинают идти назад (Джорджоне родился в 1477-м, а раздел про Беллини тянется до 1516-го), и хронология ломается.

Если лента кажется слишком широкой для страницы, есть два варианта: сократить подписи до 3–4 слов или разрезать файл на две ленты — «до 1550» и «после 1550».
